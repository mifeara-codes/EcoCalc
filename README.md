# EcoCalc

A EcoCalc é uma aplicação web desenvolvida com o objetivo de incentivar hábitos sustentáveis por meio da comparação do consumo de água e energia. A ferramenta permite visualizar possíveis economias financeiras e ambientais a partir de pequenas mudanças no cotidiano.

## Funcionalidades

- Comparação entre hábitos de consumo atuais e sustentáveis.
- Estimativa de economia mensal e anual.
- Cálculo de água e energia economizadas.
- Estimativa de redução de emissões de CO₂.
- Gráficos comparativos e dicas personalizadas.
- Alternância entre modo claro e escuro.
- Armazenamento de preferências e dados no navegador.
- Instalação como aplicativo web progressivo (PWA).

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Web App Manifest
- Service Worker

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Inicie o arquivo `index.html` utilizando a extensão Live Server.
4. Acesse a aplicação pelo navegador.

## Aplicação

A EcoCalc pode ser acessada pelo navegador e instalada em dispositivos compatíveis como um aplicativo web progressivo.

Projeto acadêmico de extensão com foco em economia sustentável e conscientização ambiental.
